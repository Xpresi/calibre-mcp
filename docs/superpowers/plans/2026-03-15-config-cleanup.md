# Config Cleanup & Repository Hygiene Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove personal filesystem paths from the calibre-mcp repo so it can be shared publicly.

**Architecture:** Six file edits + git repository initialization — no logic changes. The repo has no git history yet (`git init` is the first step). Note: `Path("").exists()` returns `True` in Python (empty string resolves to CWD), so with `library_path=""` the `validate()` will not fire "Library path not found" — instead it will fire `"metadata.db not found at: metadata.db"` (because `Path("") / "metadata.db"` = `Path("metadata.db")`, a relative path that doesn't exist).

**Tech Stack:** Python 3.10+, git

**Working directory for all commands:** `C:\Users\xpres\claude\calibre-mcp`
